## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or run a local static server:

```bash
# Using Node / npx
npx http-server . -p 8080 -c-1
```
Then visit: `http://localhost:8080`

---

## 🌐 How to Deploy to Vercel (Recommended)

1. Open your terminal in this project directory:
   ```bash
   npx vercel
   ```
2. Follow the 3-step prompt to link or deploy for free.
3. Your site will instantly be live on a fast, global CDN like `https://fahad-bin-husne-ali.vercel.app`!

---

## 🔥 How to Deploy to Firebase Hosting

1. Login to Firebase:
   ```bash
   npx firebase-tools login
   ```
2. Deploy directly using the included `firebase.json`:
   ```bash
   npx firebase-tools deploy --only hosting
   ```
